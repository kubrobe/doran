# Doran Korean

A Duolingo-style Android app for learning Korean, from Hangul up to everyday exchange-student life
(around Sejong 2B). Everything runs on the phone: no account, no internet needed after install.

- **26 units** on a lesson path: 6 Hangul units, then Basics, Everyday and Exchange life
  (campus, dorm, part-time job, transport, health, polite speech).
- **12 exercise types**: new letters, letter sounds, "which letter do you hear", word meaning,
  pick the Korean word, listen and pick, match pairs, translate with a word bank (both ways),
  tap what you hear, fill in the blank, and **speak the sentence**.
- **Real Korean audio** for every word and sentence (normal and slow), bundled in the app.
- **Pronunciation score**: your voice is recorded on the phone and checked by an offline Korean
  speech recognizer. You see a score, which syllables were heard well, and can replay your take.
- Hearts, XP, daily goal, streak, placement test, practice sessions (mistakes, listening, speaking),
  a word list with strength bars, guidebooks with grammar tips, and tap-a-word hints.

## Install on your phone

1. If an older **Doran Alley** is installed, uninstall it first (it was signed with a different key).
2. Open the latest successful **Android build** run in the Actions tab and download
   **doran-korean-phone-apk** (for almost all phones; use the 32-bit one only for very old phones).
3. Unzip it and open `app-arm64-v8a-debug.apk` on the phone. Allow "install unknown apps" if asked.

## Build it yourself

Open the folder in Android Studio and press Run, or `./gradlew assembleDebug`.
Use JDK 17 or 21 for Gradle (Settings → Build Tools → Gradle → Gradle JDK).
Every build is signed with `app/debug.keystore`, so a new build installs over the old one.

## How it fits together

| Part | Where |
|---|---|
| Course content (units, words, sentences, tips, hints) | `tools/course.txt` → `python3 tools/build_course.py` → `app/src/main/assets/course/course.json` |
| Korean audio | generated by the **Generate Korean audio** workflow (`tools/gen_audio.py`) whenever the course changes; each clip is checked with the speech recognizer, see `tools/audio_report.tsv` |
| Speech recognizer | `app/src/main/assets/asr` (sherpa-onnx Korean zipformer, int8, Apache-2.0) and `app/libs/sherpa-onnx-static-2.0.2.aar` |
| Lesson generation, answer checking, scoring, progress rules | `app/src/main/java/com/doranalley/core` (plain Kotlin, unit tested) |
| Audio playback, recording, recognition | `app/src/main/java/com/doranalley/audio` |
| Screens | `app/src/main/java/com/doranalley/ui` |
| Look and motion | colours and type in `ui/theme/Theme.kt` (Nunito, OFL, in `res/font`); shared animations in `ui/components/Motion.kt`. Motion follows the phone's animation setting, and screens only animate in (never out) so a tap can't land on a screen that is leaving |

To add or change content, edit `tools/course.txt`, run the build script, commit, and push. The audio
workflow records any new lines and commits them back.

## Tests

- **Unit tests** (`./gradlew testDebugUnitTest`): every lesson of every unit generated with 40 random
  seeds and checked for answerability; Korean word-order rules; English alternatives; pronunciation
  scoring (including numbers the recognizer writes as digits); streak, hearts and progress rules;
  every Korean line has audio.
- **Device tests** (`Device tests` workflow, Android 14 and Android 8 emulators): every audio clip
  decodes; the player plays to the end; the recognizer scores the bundled audio; the recorder never
  crashes; full lessons, placement, practice and out-of-hearts flows are played through the real UI;
  2,000 random taps without a crash. Screenshots and logs go to the `ci-screens-api34` branch.

The emulator has no real microphone, so recording quality and the score for your own voice can only be
checked on a phone: **Settings → Check your phone → Test sound / Test microphone**.
