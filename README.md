# Doran Alley (도란 골목)

An Android pilot for practising spoken Korean before an exchange semester in Korea.
The learner walks a cozy, illustrated fictional Seoul campus neighbourhood and talks
his way through small everyday problems with recurring characters.

**Status:** work in progress — first episode, *The classroom moved* (강의실이 바뀌었어요).

- Kotlin + Jetpack Compose, Android-only, `minSdk 26`, `targetSdk 35`
- No paid API required: bundled audio or an on-device Korean voice, on-device recording, Android speech recognition where available
- Interface, hints and explanations in Uzbek (Latin), Russian and English; Korean stays the language of the scene
- Scenes, Korean lines, hints and accepted replies live in content files under `app/src/main/assets/`

See the product brief in the project for the full design.
