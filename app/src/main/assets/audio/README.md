# Bundled recordings

Put reviewed Korean recordings here. Paths match the `"audio"` fields in the content files, e.g.

- `ep01/l_hello.m4a` — Minji: 아, 안녕하세요! 오늘 강의실이 바뀌었어요.
- `ep01/m_where.m4a` — model line for hint 3
- `vocab/changed.m4a` — single expression

Format: AAC in .m4a (mono, 44.1 kHz is fine). Files are stored uncompressed in the APK so they can be
streamed directly. When a file is missing, the app falls back to a clearly labelled synthetic preview
(if the phone has a Korean text-to-speech voice) or shows the text only.

Record each recurring character with one consistent voice: Minji (classmate), Seoyeon (classmate,
later teammate), Mr. Park (dorm staff), Junho (coworker). Have a proficient Korean speaker approve
both the line and the recording before setting the episode's review status to "reviewed".
